INSTALL
-------
1. Backup your live folder
2. Copy these files over your live site (keep your live .env if you prefer):
     server.js
     public/assets/aaoms-core.js
     public/assets/aaoms-core.css
     public/classroom.html
     public/admin.html
     data/classroom-slides.json
     data/chat.json          (create if missing: {"messages":[]})
     data/posts.json         (create if missing: [])
3. npm install          (only express is required)
4. Restart:  node server.js

NGINX (required for live WebSocket)
-----------------------------------

  proxy_pass http://127.0.0.1:3002;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
  proxy_set_header Host $host;
  proxy_read_timeout 86400;
}
