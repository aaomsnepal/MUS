Ownership · learn (real data)

On NEPSE, the genuine published split is usually Promoter vs Public. Public is the free float — retail and local institutions together (not a separate “FII / retail” report like India). Promoter shares can also trade as a separate line (often a P suffix, e.g. NABILP). Foreign portfolio “FII %” is not an official live series here.

Type a symbol to see promoter vs public shares from a public company page (cached).

Momentum systems · load & scan

Five well-known approaches used globally. Each is computed from real daily OHLC (not fake signals). Turn a system on, then Scan — results appear in the table. Educational only. Admin can later show/hide systems for the public.

1. Time-Series Momentum
Classic trend momentum: positive return over the lookback window (Moskowitz-style idea, daily bars).
2. Dual Momentum
Absolute momentum > 0 and stronger than NEPSE index over the same window (Antonacci idea).
3. Donchian Breakout
Turtle-style: close at/near the highest high of the last N days.
4. MACD Momentum
MACD line above signal and histogram ≥ 0 (trend confirmation).
5. RSI + Trend
RSI above 50 and price above EMA20 — momentum with trend filter.
Select systems → Scan (uses real history, limited batch)

About live market & tools

Live list (gainers, Darvas, volume…) refreshes about every 12s while the page is open. Cells flash green/red when LTP or % changes. This is session-level refresh — not broker tick-by-tick. Market hours in Nepal are roughly Sun–Thu 11:00–15:00 NPT — outside that, figures are last session. Charts use real daily OHLC history (candles, RSI, Supertrend, volume). Intraday tick-by-tick candles need a paid/live stream NEPSE does not publish freely. To add a new tracker later: compute it from the same OHLC series in the chart script (like RSI/Supertrend), or add a new screener tab from session fields in /api/nepse/live.
